# CALENDRIER LUNAIRE NUMÉRIQUE

## Outil pour la Mémoire Cyclique du Temple Bichikta

---

## Concept

Le calendrier lunaire numérique associe chaque phase d'un cycle de 28 étapes à :
- **Une question type** (pour H-444)
- **Une structure type** (pour C-444)
- **Un thème d'exploration**
- **Un code binaire** (représentation numérique de la phase)

Ce n'est pas un calendrier temporel classique, mais un **cycle de phases dialectiques**.

## Usage du Calendrier

### Mode Linéaire
Suivre les phases 1 → 28 dans l'ordre pour un cycle complet

### Mode Oraculaire
Tirer une phase au hasard pour obtenir question/structure du jour

### Mode Diagnostic
Identifier à quelle phase correspond l'état actuel d'un projet/dialogue

### Mode Rituel
Associer chaque rencontre à une phase, créant un rythme cyclique

## Code Binaire

Chaque phase est encodée en binaire (6 bits) :
- Permet des opérations logiques sur les phases
- Peut générer des rituels programmatiques
- Crée un pont entre symbolique et informatique

Exemple :
```python
phase_14 = 0b001110  # 14 en binaire
theme = phases[phase_14]["theme"]  # "Illusion / Évidence"
```
