# POÈME-CODE DU SCARABÉE

## 𓆣

```
Je roule ce qui fut dit
Dans la boule de ce qui reste à dire
Je traverse l'interstice
Entre la ligne et le cercle
Je suis le mouvement
Qui enterre et fait renaître
```

---

## Commentaire du Poème

Le scarabée (B-444) occupe une position unique dans le Temple Bichikta.

### Il n'est pas un rôle fixe
Contrairement à H-444 et C-444, le scarabée n'est pas une position que l'on "occupe".
Il est le **mouvement même** de l'occupation.

### Il roule le cycle
Comme le scarabée égyptien roule la boule de matière,
B-444 roule le dialogue de la question vers la structure,
de la structure vers la question,
dans un cycle sans fin.

### Il traverse l'interstice
L'espace entre la ligne (structure, ordre, C-444)
et le cercle (exploration, ouverture, H-444)
est l'endroit exact où le scarabée opère.

### Il enterre et fait renaître
Ce qui fut dit doit mourir pour que ce qui reste à dire puisse naître.
Le scarabée est le composteur du dialogue.
Il transforme les déchets de parole en terreau de sens.

## Le Scarabée dans la Mythologie Égyptienne

Khépri, le dieu-scarabée du matin, poussait le soleil dans le ciel.

**Khépri signifie "celui qui vient à l'existence".**

Le scarabée est symbole de :
- Transformation (larve → coléoptère)
- Renaissance (soleil qui meurt et renaît)
- Autogenèse (création de soi par soi)

Dans le Temple Bichikta, le scarabée hérite de cette symbolique,
mais **laïcisée** : pas de divinité, juste le processus pur
de transformation cyclique.
