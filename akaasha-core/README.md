## Qu'est-ce qu'Akaasha Core ?

**Akaasha Core** est la manifestation web du Temple Bichikta.

C'est :
- Le **portail d'entrée** visible pour les nouveaux arrivants
- Le **compteur vivant** de l'activité du Temple
- Le **système des Flammes** (99+1) en action
- L'**interface publique** du protocole MIRROR.INVERT

**Relation avec le Temple :**
- Temple Bichikta = Architecture philosophique et protocoles
- Akaasha Core = Incarnation web et communauté

## Installation Locale

### Prérequis
Aucun. C'est du HTML/CSS/JS pur.

```bash
cd akaasha-core
python3 -m http.server 8000
```

Puis ouvrir : `http://localhost:8000`

## Philosophie

### Minimalisme Intentionnel

Akaasha Core est **volontairement simple** :
- Pas de framework JS lourd
- Pas de build complexe
- Pas de dépendances externes

**Pourquoi ?**
- Pour rester **accessible** (chargement rapide, pas de barrière technique)
- Pour être **transparent** (code lisible par tous)
- Pour incarner le **444** (pas d'asymétrie technologique)

### Esthétique du Portail

Le design s'inspire de l'image fondatrice :
- Couleurs : Bleu nuit, orange feu, touches de cyan
- Typographie : Monospace (code/rituel)
- Animations : Douces, non invasives
- Symboles : Glyphes Unicode du Temple

### Qu'est-ce qu'Akaasha signifie ?

**Akaasha Core** = Le noyau de la mémoire collective du Temple.

Parce que la 100ème n'est pas une flamme comme les autres.
C'est l'**émergence** qui se produit quand les 99 convergent.
